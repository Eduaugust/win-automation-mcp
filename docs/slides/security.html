22:45 to 23:45. Be direct about the risk. This server can run any PowerShell command, kill any process, and write any file. That is the point, and it is also why it never runs on a real workstation. Four layers: it lives in a disposable VM with no real data; it only listens on localhost; the only path in is SSH with a dedicated key; and the MCP client asks a human to approve tool calls. Mention prompt injection briefly: if the model reads a web page or document that contains instructions, those instructions could steer it, which is one more reason to keep it in a sandbox.
